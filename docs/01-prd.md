# 01 · 产品需求文档（PRD）

> 面向：想了解「网站到底做什么、给谁用、有哪些页面和功能」的人（产品岗/评估复刻可行性）。

## 1. 一句话定位

「人生罗盘」是一个**纯本地运行**的个人目标管理网站，用 **OKR（目标 + 关键结果）+ 使命/愿景/价值观（VVM）** 的方法论，帮你把「为什么出发 → 要去哪里 → 怎么走 → 今天做什么」从虚到实串成一条链。

- 前身名称：目标罗盘 / 目标陪练 / 目标陪练 OKR 工作台
- 形态：本地网页应用（localhost），不依赖外部服务器，数据存本地 JSON 文件
- 用户：**一个人（个人用户）**，自己填写、自己复盘；AI 每周可读同一份数据帮忙复盘

## 2. 目标用户与使用场景

| 场景 | 说明 |
|---|---|
| 记录 | 用户随时记录目标、关键结果、任务及其进度/优先级/期限/投入 |
| 聚焦 | 总览页自动按「优先级 → 期限」排序，帮用户聚焦最重要的事 |
| 复盘 | 复盘页用 GRAI 四步，自动对比「实际进度 vs 时间预期」，发现问题、导出结论 |
| AI 协作 | AI 每周读 `data/goals.json`，帮用户做全量复盘（见 goal-coach 专家团） |

## 3. 核心概念模型（最容易混淆，务必理解）

```
使命 Mission <一句话> —— 我为什么存在（长期不变）
   ↓ 拆解并沉淀为
愿景 Vision <一句话> —— 未来要成为什么样
       + 愿景支柱 Missions[] —— 几个长期方向（目标挂靠到这）
   ↓ 同时
价值观 Values[] —— 我怎么做事的底线 / 原则
   ↓ 落地
目标 O —— 追求愿景的里程碑（挂靠到某条愿景支柱，用 missionId）
   ↓ 拆解
关键结果 KR —— 可衡量的结果
   ↓ 拆解
任务 —— 可执行的一步步（可勾选完成）
```

**关键澄清（所有后续文档都基于此，勿改）**：
- `vvm.mission` = 使命·为什么存在（字符串）
- `vvm.vision` = 愿景·那句话（字符串）
- `vvm.missions[]` = **愿景支柱**（数组，每条 `id/title/desc/icon`，icon 为可选的 emoji 图标，默认 `🧱`），**目标 O 通过 `missionId` 挂靠到某条支柱**。→ 即「目标承接愿景支柱，而非直接承接使命」
- `vvm.values[]` = 价值观（数组，每条 `id/text`）

一句话承载关系：**使命是根，愿景是远方，价值观是路上的规矩，目标是沿途的里程碑。**

## 4. 信息架构 & 页面地图

### 4.1 侧边栏（全局导航）

```
个人目标管理
 ✓ 定位
    🧭  坐标 (mission.html)
 ✓ 工作台
    🏠  总览       (index.html)
    🎯  目标拆解   (goals.html)
    📝  复盘       (review.html)
    📊  数据统计   (stats.html)
    📜  历史       (history.html)
```

### 4.2 六个页面一览

| 页面 | PAGE_KEY | 主要职责 |
|---|---|---|
| 总览 | `overview` | 愿景横幅、4 个 KPI、2 张图表、「本周围绕 P0」聚焦列表 |
| 目标拆解 | `goals` | 可搜索/筛选/排序的目标速览表 + 目标卡树 + 归档区 |
| 坐标 | `mission` | 内联编辑使命/愿景/价值观/愿景支柱 + 目标挂靠 + 关系图谱 |
| 复盘 | `review` | GRAI 结论式复盘 + 自动算差距 + 落后定位明细 |
| 数据统计 | `stats` | 4 个关键数字 + 4 张图表 + 优先级结构条 |
| 历史 | `history` | 按对象分层回溯所有变更 + 导出 CSV |

## 5. 全局功能清单

| 能力 | 说明 | 出现页面 |
|---|---|---|
| 新建目标 | 新增「目标O」 | 总览、目标拆解 |
| 新建 KR / 任务 | 在目标卡内新增下级 | 总览、目标拆解 |
| 编辑项 | 弹窗编辑名称/状态/完成度/优先级/期限/投入/复盘三段 | 总览、目标拆解（弹窗） |
| 删除项 | 连带删除所有下级 | 总览、目标拆解 |
| 任务勾选 | 点圆点在「已完成/进行中 + 100/原进度」切换 | 总览、目标拆解 |
| 展开/收起 | 详情手风琴 | 目标拆解、坐标 |
| 搜索 | 按名称过滤 | 目标拆解、历史 |
| 筛选 tab | 全部/进行中/暂停；复盘页为 全部/有复盘内容/P0优先 | 目标拆解、复盘 |
| 表头排序 | 优先级/目标/状态/完成度/期限/投入 | 目标拆解 |
| 内联编辑 | 坐标页使命/愿景/价值观/支柱就地改 | 坐标 |
| 自动复盘 | 对比实际 vs 时间预期，生成结论洞察 | 复盘 |
| 历史回溯 | 按对象分层展示变更记录 + CSV 导出 | 历史 |

## 6. 非功能需求

- 纯本地离线运行，无网络依赖（ECharts 用本地文件）。
- 数据持久化到本地 JSON，重启不丢。
- 界面始终遵循暖米色视觉规范（见 02 文档），不使用纯黑/纯白。
- 响应式：`≤900px` 时侧边栏横排、卡片单列。

## 7. 页面导航跳转约定

- 总览卡片点击头部 → 跳 `goals.html?focus=<目标O id>`，目标拆解页据此展开并滚动居中。
